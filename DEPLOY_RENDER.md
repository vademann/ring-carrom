# Бесплатный тестовый сервер Render

Статус: исходники подготовлены; облачный сервис ещё не создан. Для публикации требуется подключённый аккаунт Render и доступный ему Git-репозиторий. Платные ресурсы не создаются.

## Публикация

1. Создать аккаунт https://dashboard.render.com/register и подключить интеграцию Render в Codex. Секреты в чат не отправлять.
2. `python package-cloud.py` создаёт `deploy/ring-carrom-render.zip`: только актуальный сервер и игровые assets. В архиве нет SQLite, старых социальных данных, секретов установок, журналов, локальных настроек или APK.
3. Распаковать архив в корень отдельного GitHub/GitLab репозитория и предоставить Render доступ к нему. Существующий локальный сервер и базы не переносить автоматически.
4. В Render создать Blueprint из этого репозитория (`render.yaml`), проверить **Free**, один Web Service, без дисков и баз. Или создать Python Web Service вручную: Frankfurt, build `pip install -r requirements.txt`, start `python -u server.py`, health `/health`, plan Free. Один процесс/экземпляр: комнаты и пересылка находятся в RAM.
5. Render задаёт `PORT` и `RENDER_EXTERNAL_URL`. Сервер слушает `0.0.0.0:$PORT`; `/config` возвращает его постоянный WSS-адрес. TLS и WebSocket обслуживает платформа. Браузерная игра доступна на корневом HTTPS-адресе.
6. После успешного deploy проверить `/health`, `/config`, два независимых клиента, заявки, переписку и матч. Затем выполнить `./use-cloud-server.ps1 -ServerUrl https://ИМЯ.onrender.com`. Скрипт проверяет сервис и пересобирает APK с его точным адресом; при ошибке сборки восстанавливает прежнюю конфигурацию.

Нативный Android-мост доверяет точным HTTPS-хостам, встроенным в `server-config.js` APK. Общий доступ ко всем доменам Render не разрешается. Debug HTTP-исключение для эмулятора сохранено; в release HTTP не добавлялся.

## Ограничения бесплатного тарифа

Render усыпляет сервис после 15 минут без входящих HTTP/WebSocket сообщений. Пробуждение занимает примерно минуту, поэтому первое подключение может потребовать повторной попытки. Включены 750 часов в месяц на workspace, также действуют квоты трафика и сборок. Не включать платные тарифы/автоматическую оплату превышения; при исчерпании квоты сервис может остановиться. Актуальные условия: https://render.com/docs/free и https://render.com/docs/websocket .

Друзья, заявки, переписка и очередь остаются на телефонах. Перезапуск облачного процесса завершает текущие комнаты, теряет маршруты и транзит; устройства снова регистрируются и повторяют неподтверждённую доставку.

Важно: имеющаяся игровая карьера/рейтинг использует серверную SQLite. Файловая система бесплатного Render временная: рейтинг/история на облачном сервере могут сбрасываться при рестарте/усыплении/deploy. Локальная существующая база не удаляется и не выгружается. Для постоянного глобального рейтинга позже потребуется отдельное долговременное хранилище; друзья от него не зависят. Бесплатная Render Postgres не добавлялась — её срок ограничен 30 днями.

Архив является исходниками для Git-репозитория, не прямым ZIP-deploy: Render собирает код из репозитория. После создания настоящего сервиса обновить этот документ его URL и результатами публичной проверки; заранее адрес в APK не подставляется.
